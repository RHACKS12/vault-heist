# Presentation assets

These assets are local and require no third-party service at runtime.

## Original SVG artwork

- `vault-mark.svg`: circular safe-wheel project mark in brick red and ink, 64 x 64 view box.
- `favicon.svg`: simplified safe wheel in cream on red, 64 x 64 view box.
- `skyline.svg`: original San Antonio-inspired skyline with an observation tower, 1440 x 220 view box. Decorative rather than a geographically exact city profile.
- `icons.svg`: original 24 x 24 icon set, with a 1.7-unit stroke, square line ends and miter joins. Symbols: `arrow-right`, `play`, `record`, `replay`, `volume`, `lock`, `reset`, `users`, `coins`, `vault`, `search`, `folder`, `file`, and `flag`. Use an external SVG `<use>` reference. Add accessible labels to the surrounding control and hide decorative icons from assistive technology.

The colors and line-art treatment follow the RowdyHacks kickoff deck's cream paper, brick-red print, bold display type, and city-skyline direction. The safe wheel connects that direction to this project's vault-race concept. These are original project assets; they are not official event or sponsor logos.

## Fonts

Downloaded unchanged on 2026-10-04 from the official [Google Fonts repository](https://github.com/google/fonts). Both font families use the SIL Open Font License 1.1. Full copyright and license texts accompany the font files.

- [Bungee Regular](https://github.com/google/fonts/blob/main/ofl/bungee/Bungee-Regular.ttf): `fonts/Bungee-Regular.ttf`; license `fonts/OFL-Bungee.txt`.
- [Courier Prime Regular](https://github.com/google/fonts/blob/main/ofl/courierprime/CourierPrime-Regular.ttf): `fonts/CourierPrime-Regular.ttf`; license `fonts/OFL-CourierPrime.txt`.
- [Courier Prime Bold](https://github.com/google/fonts/blob/main/ofl/courierprime/CourierPrime-Bold.ttf): `fonts/CourierPrime-Bold.ttf`; same Courier Prime license.

Bungee is an intentional approximation of the deck's chunky display lettering; the PDF does not name its typeface. Courier Prime provides the printed instruction-sheet voice for supporting text and interface controls.
